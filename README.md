# Yume Sushi — Site de restaurante (HTML e CSS)

Site estático de um restaurante de culinária japonesa fictício, criado durante o curso técnico de Análise e Desenvolvimento de Sistemas. O objetivo foi praticar estrutura HTML, estilização com CSS e organização de várias páginas.

## Páginas

- **Início** (`index.html`): apresentação do restaurante
- **Sobre nós** (`sobre-nos.html`): história e fotos do restaurante
- **Cardápio** (`cardapio.html`): pratos com imagens
- **Fale conosco** (`fale-conosco.html`): informações de contato

## Tecnologias

HTML5 e CSS3, sem frameworks e sem JavaScript.

## Como ver o site

Baixe ou clone o repositório e abra o `index.html` no navegador.

```bash
git clone https://github.com/Gabrielmachado01gg/Site_web.git
cd Site_web
# abra o index.html no navegador
```
